# Worms Online app

The desktop app for [Worms Online](https://wormsonline.net/): the website in its own window, without the limits browsers put on games (background throttling, GPU blocklists, power saving).

Downloads: https://wormsonline.net/#download

- `npm start` runs it from the source.
- `npm run dist:win` builds the Windows installer; macOS and Linux are built by the `build` workflow (Actions tab).
